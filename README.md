# 🫧 Xiaomi Liquid Glass Stats Widget

Кастомный Android-виджет активности (**шаги, килокалории, минуты активности и кольцо прогресса**) в эстетике **Liquid Glass** (полупрозрачное матовое стекло с тонким световым бликом по контуру в стиле HyperOS / iOS 26), интегрированный с системным шагомером **Xiaomi (MIUI / HyperOS)** и аппаратным датчиком шагов Android.

---

## ✨ Особенности

- **Дизайн Liquid Glass**:
  - Полупрозрачная стеклянная подложка с мягким тонированием (`#28181A20`) и градиентным диагональным бликом по краям (`1.2dp` контур с отражением света сверху-слева и снизу-справа).
  - Отрисовка кольца прогресса с эффектом свечения (`BlurMaskFilter`) и плавным градиентом (`#FF7A59` → `#FF5733`) на `Canvas` в высоком разрешении.
  - Полная адаптация под любые светлые и тёмные обои рабочего стола (включая размытие фона окна в приложении настройки).
- **Прямая работа с шагомером Xiaomi (MIUI / HyperOS)**:
  1. **Системный провайдер Xiaomi (`content://com.miui.providers.steps/item`)**: чтение точного количества шагов за текущие сутки напрямую из встроенного системного шагомера MIUI / HyperOS (тот же источник, который используют стандартные виджеты Ленты виджетов и Mi Fitness).
  2. **Аппаратный датчик Android (`Sensor.TYPE_STEP_COUNTER`)**: автоматический фолбэк с сохранением базового значения в полночь (`SharedPreferences`), благодаря чему виджет работает даже без сервисов Xiaomi или при закрытом доступе к провайдеру.
  3. **Автоматический расчёт калорий и минут**: вычисление сожжённых ккал (`~0.045–0.068 ккал/шаг` с учётом веса и длины шага) и активных минут (`~100 шагов/мин`).
- **Настраиваемый внешний вид и цели**:
  - Настройка дневной цели по шагам (по умолчанию `6 000` или `10 000`).
  - Регулировка прозрачности стекла, яркости блика рамки и цвета кольца активности прямо из приложения.
  - Обновление по тапу на виджет, при включении экрана и через `WorkManager` каждые 15 минут.
- **Автосборка APK через GitHub Actions**:
  - При каждом `push` в ветку `main` или вручную во вкладке **Actions** автоматически собирается готовый к установке `app-debug.apk`.

## 🚀 Как собрать APK на GitHub (без установки Android Studio)

1. Создайте новый репозиторий на GitHub и загрузите туда содержимое этого архива.
2. Перейдите во вкладку **Actions** вашего репозитория.
3. Выберите workflow **Build Liquid Glass Widget APK** и нажмите **Run workflow** (или просто сделайте любой коммит в `main`).
4. Через ~2 минуты скачайте готовый файл **`xiaomi-liquid-glass-widget-apk`** в разделе **Artifacts** завершённого билда.

## 🛠 Сборка локально через Android Studio

1. Откройте папку проекта в **Android Studio Ladybug (2024.2.1)** или новее.
2. Дождитесь завершения синхронизации Gradle (`Gradle Sync`).
3. Нажмите **Run 'app'** (`Shift + F10`) или выполните в терминале:
   ```bash
   ./gradlew assembleDebug
   ```
4. После установки откройте приложение **Liquid Glass Статистика**, выдайте разрешение **«Физическая активность»** и добавьте виджет **«Статистика (Liquid Glass)»** (размер `2×2`) на рабочий стол.
